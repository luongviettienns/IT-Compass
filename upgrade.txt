# Business Flow Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nối các module hiện có thành một flow nghiệp vụ end-to-end đủ chặt để website trông như một platform vận hành thật, không chỉ là tập hợp màn hình rời.

**Architecture:** Tập trung vào một luồng chính: `guest → auth → profile → assessment → recommendation → booking → messaging/follow-up → mentor/admin handling`. Mỗi phase phải tạo ra trạng thái rõ ràng, chuyển tiếp có điều kiện, và màn hình/endpoint hỗ trợ trạng thái đó. Ưu tiên tối ưu luồng người dùng trước, rồi mới thêm polish và proof-of-quality.

**Tech Stack:** React + Vite + TypeScript + React Router + React Query + Socket.IO client, Node.js + Express + TypeScript + Prisma + Socket.IO + Zod + Redis.
